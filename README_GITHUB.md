# EDOTH Assistant — Build APK Tanpa Android Studio

## Alur
1. Buat repository GitHub baru, misalnya `EDOTH-Assistant`.
2. Upload **seluruh isi folder project ini** ke repository.
3. Pastikan branch utama bernama `main`.
4. Buka tab **Actions**.
5. Workflow **Build EDOTH Assistant APK** akan berjalan otomatis setelah push.
6. Setelah selesai, buka hasil workflow dan download artifact:
   `EDOTH-Assistant-debug`
7. Di dalamnya ada `app-debug.apk`.

## Catatan
Project ini adalah versi awal: speech-to-text Bahasa Indonesia + text-to-speech.
Fitur wake word seperti “Hey EDOTH” dan koneksi AI akan ditambahkan setelah APK dasar berhasil dipasang dan diuji.
